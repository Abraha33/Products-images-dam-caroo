# Reports

Los resultados reales de la auditoría se generan localmente y no se versionan por defecto.

Esta carpeta solo documenta el formato y, si se aprueba más adelante, podrá contener resúmenes sanitizados o ejemplos pequeños sin imágenes fuente ni datos sensibles.

Outputs esperados localmente:

- inventory.csv
- products_summary.csv
- duplicates_exact.csv
- duplicates_visual.csv
- quality_flags.csv
- coverage_by_product.csv
- audit_summary.md
- audit_config.json
- audit_errors.log
